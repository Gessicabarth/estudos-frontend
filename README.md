# Estudos em Front-End

## 💻 Sobre o Repositório
Este repositório atua como o meu diretório centralizador de estudos, práticas e projetos focados em desenvolvimento web. O objetivo deste espaço é a aplicação e a prática dos conceitos fundamentais de Front-End.

## 📂 Estrutura de Diretórios
Os projetos estão isolados em suas respectivas pastas para facilitar a navegação e a leitura do código:

* **`/blog-pessoal`:** Estruturação inicial da base visual (background) do blog, utilizando HTML, CSS e JavaScript para estabelecer a mesma identidade visual aplicada no meu portfólio principal.
* **`/esboco-blog-html`:** Estruturação inicial em HTML para o blog, focada na semântica da página e na organização inicial do layout.
* **`/formulario-cadastro-devs`:** Desenvolvimento de um formulário interativo de cadastro, construído a partir da aplicação de conceitos de layout abordados em um projeto prático guiado pela instrutora Rafaela Ballerini.
* **`/landing-page-html-css`:** Criação de uma página de aterrissagem para praticar o posicionamento de elementos e a responsividade, desenvolvida por meio de um projeto guiado por Rafaela Ballerini.
* **`/projetos-web-html-css`:** Agrupamento de práticas e implementações de estruturação e estilização de páginas web, desenvolvidas durante a formação em HTML e CSS da plataforma Alura.

## 🛠️ Tecnologias Utilizadas
